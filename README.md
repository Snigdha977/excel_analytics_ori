# 📊 Excel Analytics

**Excel Analytics** is a full-stack MERN application that allows users to upload `.xlsx` and `.xls` files, providing interactive charts, graphs, and comprehensive data analysis.

---

## ✨ Features

- Upload and parse Excel files (`.xlsx`, `.xls`)  
- Display interactive charts and graphs  
- Generate overall data analysis and insights  
- User-friendly interface for seamless interaction  

---

## 🛠 Tech Stack

- **Frontend:** React, JavaScript, CSS  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Data Processing:** Excel file handling and analysis  

---
